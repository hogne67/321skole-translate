# Podcast sound library

Legg ferdige, rettighetsklare podcastlyder i denne mappen.

Filer som brukes av V1-biblioteket:

- `intro-warm.mp3`
- `intro-bright.mp3`
- `intro-news.mp3`
- `transition-ding.mp3`
- `transition-soft.mp3`
- `effect-clap.mp3`
- `effect-success.mp3`
- `effect-wow.mp3`
- `outro-soft.mp3`
- `outro-bright.mp3`

Anbefalinger:

- Intro/outro: 3-5 sekunder.
- Overganger/effekter: 0.5-2 sekunder.
- Bruk lav til moderat lydstyrke, slik at lydene ikke overdøver elevens tale.
- MP3 er enklest for nettleserstotte. Unnga personstemmer i standardbiblioteket.

Hvis en fil mangler, spiller appen en enkel innebygd fallback-lyd i betaen.
